TO RUN THIS CODE:
You will need to get an API key from OpenAI.
Then, open a code editor.
In your project, add ".venv" from Python, then add a file .env underneath that

To add the API key: 
  (in .env file)
      OPENAI_API_KEY="your API key here"
  
  Then, in the file ".gitignore" (should be in .venv folder), write the following code
      .venv/
      env
      pip install opencv-python

From there, you can download the files in my repository and use them to run each function of Sprite!
